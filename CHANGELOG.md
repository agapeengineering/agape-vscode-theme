# Changelog

## 0.1.0 — 2026-10-22

- Introduced **agape Light** and **agape Dark** with coordinated workbench, syntax, semantic, terminal, Git, diff and diagnostic colors.
- Added saturated dark syntax on Adobe for Light and distinct bright syntax on graphite for Dark.
- Added an isolated preview, synthetic language samples, repeatable generation and automated color checks.
- Included local VSIX packaging and validation CI.
- Published the first GitHub release with a manually installable VSIX and SHA-256 checksum. Marketplace and Open VSX publication are pending.
